Let me hand-build a tiny 2-chain toy structure (correct fixed-column PDB format) so we can see BioPython turn text into objects, then we'll do the same thing on the real 1BRS.The PDB format is column-fixed, not whitespace-delimited — that matters:

| Columns | Field | Example |
|---|---|---|
| 1–6 | Record type | `ATOM` |
| 7–11 | Atom serial | `1` |
| 13–16 | Atom name | `CA` |
| 18–20 | Residue name | `ALA` |
| 22 | **Chain ID** | `A` |
| 23–26 | Residue seq number | `1` |
| 31–38 / 39–46 / 47–54 | x / y / z (Å) | `0.000` |

BioPython's parser reads by these column offsets, not by splitting on spaces — that's why a residue name can butt right up against a chain ID with no space and still parse correctly. **What just happened, stage by stage:**
- **Distance matrix**: raw N_A×N_B CA–CA distances in Å, computed by hand with numpy broadcasting (`(NA,1,3) - (1,NB,3) → (NA,NB,3) → norm`). No hidden library call — that *is* the pairwise-distance computation.
- **Contact matrix**: `dist <= threshold` turns it into 0/1. I used 8 Å here (a common loose "backbone contact" radius). For a real interface definition, tighter thresholds are standard — 4.5–5 Å using *heavy-atom* (all-atom, not just CA) minimum distance is the literature-standard "true interface" cutoff. CA–CA at 8 Å is more forgiving/coarse — good for building a structural *graph*, too loose for labeling "this residue physically touches the partner."
- **Interface labels**: a residue is interface=1 if its row (or column) in the contact matrix has *any* 1 — i.e., it touches the other chain anywhere. ALA/GLY/SER on chain A came out interface=1 because I placed them geometrically near chain B; LEU didn't.
- **Intra-chain edge_index**: this is the graph a GNN would actually be given at inference time — each chain's *own* structural contact graph (not the cross-chain one, since predicting an unknown interface means you don't get to see cross-chain contacts as input).
